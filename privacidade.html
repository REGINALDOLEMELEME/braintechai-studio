Política de privacidade

Última atualização: 20 de novembro de 2026

O que é

O BrainTechAI Studio é uma ferramenta de uso pessoal, que roda no computador do dono do canal BrainTechAI (@braintechaibr). Não é oferecida ao público e não tem cadastro de usuários.

Dados do Google e do YouTube que o app acessa

Com a autorização do dono do canal, pela tela de consentimento do Google, o app usa a YouTube Data API para:

  • Enviar vídeos (permissão youtube.upload): envia ao próprio canal, sempre como privados, os vídeos que o dono aprovou;
  • Ler dados (permissão youtube.readonly): confere que a conta autorizada é a do canal @braintechaibr e consulta dados públicos do YouTube (títulos, números de visualizações e descrições de vídeos públicos sobre inteligência artificial) para sugerir pautas.

Como os dados são usados e guardados

  • Os tokens de acesso ficam apenas no computador do dono do canal, fora de qualquer servidor, e podem ser apagados a qualquer momento.
  • Os dados públicos consultados servem só para montar a pauta do próprio canal e ficam no banco de dados local do app.
  • Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade nem transferido para outros serviços.
  • O uso dos dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Depois disso, o app não consegue mais acessar a conta.
